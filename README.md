# Krismas

Small quality-of-life plugins for [Valenced](https://github.com/Valenced/valenced), a client modification for Discord mobile.

## Plugins

### Verity Spoiler
Hides the word "verity" in other people's messages behind a spoiler box, so you don't have to suffer.

- Only affects messages from other people. Your own messages are untouched.
- Matches whole words only, ignoring case.
- Skips code blocks, links and mentions.
- Optional setting: hide the entire message instead of just the word.

### Local Renamer
Rename servers and channels on your own device. Nobody else sees the new names.

- Add a name by pasting a server or channel ID, then typing the name you want.
- Remove a name by tapping it in the plugin's settings.
- Names apply after a reload, and the settings page has a reload button.

Finding an ID: turn on Developer Mode in Discord's settings, then right-click a server or channel and choose **Copy ID**.
